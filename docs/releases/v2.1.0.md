# School Planner v2.1.0

Диалоги редактирования в Telegram теперь сохраняются в PostgreSQL и переживают
перезапуск бота. Срок хранения после последней записи состояния или данных —
семь дней; он настраивается через `FSM_TTL_SECONDS`.

Версии CSS и JavaScript вычисляются по содержимому файлов. Главная страница и
совместимые точки входа для старых клиентов получают актуальные ссылки
автоматически; ручное обновление номера версии ресурсов больше не требуется.

Добавлен `scripts/deploy-production.sh`: проверка выбранного commit и production
конфигурации, резервное копирование с репетицией восстановления, миграции,
обновление приложения без пересоздания БД и проверка здоровья. При сбое скрипт
пытается восстановить прежние контейнеры или образ приложения.

## Обновление

Примените миграцию `0003_fsm_storage.sql` перед запуском нового бота.
Существующие диалоги из памяти прежнего процесса не переносятся. Миграция
добавляет отдельную таблицу и совместима с предыдущим приложением.

См. [порядок безопасного обновления](../safe-update.md). Автоматический откат
приложения не восстанавливает БД. Внешнее резервное хранилище настраивается
отдельно.

## Проверки

Пройдены интеграционные тесты PostgreSQL 16, браузерные сценарии Chromium
на desktop/mobile, проверки сохранения и конкурентного обновления FSM,
версионирования ресурсов, dry-run и восстановления после частичной остановки.
Проверены Ruff, синтаксис Bash и сборка Docker.
