# Бот, который собирает школьное расписание в один календарь — мой ClassMatePlannerBot

Если у вас в семье одновременно школа, кружки и репетиторы, то расписание быстро превращается в хаос. Я сделал Telegram-бота **@ClassMatePlannerBot**, который собирает уроки и внеурочку в единый, понятный список — с проверками пересечений и удобными командами. Ниже — живой обзор, примеры команд и немного «кухни», на чем все сделано.

## Кому будет полезен
- родителям, которые ведут расписание ребенка;
- школьникам и студентам с плотным графиком;
- тем, кто хочет делиться расписанием с членами семьи одним кликом.

## Что умеет бот
- хранит **уроки** и **внеурочку** отдельно, но показывает их вместе;
- выводит **расписание на сегодня** и **на всю неделю**;
- не дает сохранить пересекающиеся занятия;
- ограничивает размер дня (12 уроков и 6 внеурочек — чтобы не превратить список в стену текста);
- умеет делиться расписанием по ссылке (срок действия — 1 день).

## Примеры, как это выглядит в жизни
**Сценарий 1: собираю расписание за 5 минут**  
Пишу уроки по шаблону и сохраняю:
```
08:30-09:15 Математика 204 (Иванова)
09:25-10:10 Русский 312
10:30-11:15 Английский
```
А потом добавляю внеурочку на тот же день:
```
16:00-17:00 Робототехника к.12
18:30-19:30 Плавание бассейн
```
Бот проверит, нет ли пересечений, и сохранит только корректное расписание.

**Сценарий 2: один раз ввел — все видят**  
Делаю `/share`, отправляю ссылку маме/папе — и у них автоматически появляется мое расписание.

## Быстрый старт
1. Откройте **@ClassMatePlannerBot**.
2. Нажмите `/start`.
3. Добавьте расписание через `/set_lessons` и `/set_extras`.
4. Проверяйте день через `/today` или всю неделю через `/week`.

## Формат ввода занятий
```
08:30-09:15 Математика 204 (Иванова)
16:00-17:00 Робототехника к.12
```
Можно добавлять локацию и комментарии, разделяя пробелами, `|` или `;`.

## Команды, которые пригодятся чаще всего
- `/set_lessons` — заполнить уроки выбранного дня.
- `/set_extras` — заполнить кружки/секции выбранного дня.
- `/today` — список занятий на сегодня (уроки + внеурочка).
- `/week` — расписание на неделю.
- `/share` — ссылка для передачи расписания другому человеку.
- `/edit` — отредактировать или удалить отдельную запись.

## Делюсь расписанием с семьей
Команда `/share` создает ссылку, по которой другой человек может импортировать ваше расписание. Есть два режима:
1) уроки + внеурочка;  
2) только уроки.  
Ссылка живет сутки, потом можно сгенерировать новую.

## На чем это сделано (технологии)
- **Python 3.11 + aiogram 3** — Telegram-бот и обработчики команд.
- **PostgreSQL 15 + asyncpg** — хранение расписаний, уроков и внеурочки.
- **Docker + docker-compose** — быстрый запуск и простое развертывание.
- Есть health-эндпоинт для мониторинга контейнера, а для WebApp предусмотрен отдельный FastAPI-сервис (его можно подключить при желании).

## Почему это удобно
- все занятия в одном месте — не нужно переключаться между чатами и заметками;
- нет дублей и пересечений;
- формат быстрый: ввел построчно и готово;
- можно синхронизировать расписание между родителями и ребенком.
